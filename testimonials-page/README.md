# Testimonials Page — Sales Fortuna

A responsive testimonial carousel built with React and SCSS, based on a Figma design.

## ✨ Features

- Responsive layout (1–3 cards visible depending on screen size)
- Carousel navigation with arrows
- Styled with SCSS (BEM-naming)
- Deployable via GitHub Pages

## 📦 Tech Stack

- React (Vite / Create React App)
- SCSS Modules
- JavaScript (ES6+)
